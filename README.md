This is a opposum trivia game!
My program, when ran, takes you through three levels of questions 
about oppossums, getting harder at each level!
To run the program use the command:  ./opossum_trivia

For the required list:

-In my code Question and QuizGame classes use private variables and 
public functions.

-Created a Make file and make clean capabilities

-Use separate source files

-Used std::vector to store the questions and awnser choices.
 
-Used pass by reference in askQuestion(int& score) so the Question class 
can update the player's score. I also used it in 
playLevel(const int& level) to pass the level number.

-Used cin and cout to take in the players name and awnsers and display
different banners like the title and score.

-Used loops to display the multipule choice awnsers, move through the 
levels, and to access the questions that were in the vector.
